# nhatminhtrange.github.io

Personal website of **Minh Nhat Tran** — PhD student in Geophysics at the University of Houston.

🌐 **Live site:** [nhatminhtrange.github.io](https://nhatminhtrange.github.io)

## About

A static, single-page personal website built with vanilla HTML/CSS/JS — no build step, no dependencies, no JavaScript framework. Just a single `index.html` you can open anywhere.

## Stack

- Pure HTML + CSS + a tiny `IntersectionObserver` script
- Google Fonts: **Fraunces** (serif) + **JetBrains Mono**
- Inline SVG seismic-trace illustration
- Fully responsive (mobile-first breakpoints)

## Sections

1. **Hero** — Name, tagline, animated seismic-trace visual
2. **About** — Bio + current focus + toolkit
3. **Journey** — Education & research timeline
4. **Research** — FWI, DAS, wave propagation, HPC
5. **Contact** — Emails, GitHub, Google Scholar

## Deploy

This repo is configured for **GitHub Pages**. Any push to the `main` branch is published automatically at `https://nhatminhtrange.github.io`.

To run locally:

```bash
git clone https://github.com/nhatminhtrange/nhatminhtrange.github.io.git
cd nhatminhtrange.github.io
# open index.html in your browser — that's it
```

Or with a quick local server:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```
